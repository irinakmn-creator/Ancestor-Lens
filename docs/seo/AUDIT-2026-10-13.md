# Ancestor Lens SEO audit — October 13, 2026

## Scope and evidence

Inspected all 59 root HTML files, CSS, shared JavaScript, translations, sitemap, robots, generators, maintenance scripts and assets. There are 55 content pages (homepage, blog index and 53 articles), plus four pre-existing meta-refresh alias pages. A read-only live crawl checked all repository pages, `/`, robots, sitemap and `/about.html`: all public site pages and crawl files returned HTTP 200; `/about.html` returned 404. No `X-Robots-Tag` exclusion was observed. This is crawlability evidence, not evidence that Google indexed or ranked a URL.

The full pre-edit URL inventory, titles, descriptions, H1–H3 headings, canonical tags, schemas, links and flags are in [baseline.csv](baseline.csv) and [baseline.json](baseline.json). Run `python3 tools/seo_audit.py --output docs/seo/current` to regenerate the local audit. Live response and storefront evidence will be preserved alongside this report.

No Search Console, Clarity dashboard, App Store Connect or Play Console data was supplied. Rankings, impressions, organic traffic, search volume, install attribution and conversions remain unmeasured. Local browser timings are diagnostic only; field Core Web Vitals require CrUX/Search Console or real-user measurement.

## Priority 2 — content intent and localization

Baseline heading review found 42 pages whose first content heading after H1 was H3 (often the intro CTA or blog cards). Correct the four priority intro CTAs to H2, retaining their appearance, and add an accessible H2 above the blog card collection. Other legacy heading skips remain editorial follow-ups in the full heading inventory. Seventeen baseline titles exceed 65 characters; this is a truncation review threshold, not a Google character-limit rule. Preserve nonpriority titles pending query intent review.

All four priority URLs are preserved. Metadata and helpful additions differentiate their purpose:

## Manual verification required

- Search Console: ownership, Google-selected canonical, indexed pages, impressions/clicks/query overlap, country and page reports, sitemap submission and URL inspections.
- App Store Connect / Play Console: full country availability, active IAP/subscription models, prices by storefront, device/OS support, current feature parity and install attribution.
- Product/backend owner: photo processing location/provider, retention, logs/backups, deletion, opt-outs, precise timing and any validation study.
- Testimonial source records or store review permalinks before restoring quoted reviews/rating schema.
- Current official feature screenshots: the reused App Store screenshots show published UI, not independently reproduced current results or evidence of accuracy. Release/version and Android parity need owner confirmation.
- Clarity dashboard: consent configuration, domain/project access, referral and country filters, custom event visibility and any existing smart-event overlap. Website privacy disclosure must describe web analytics separately from app privacy.
- PageSpeed Insights/CrUX and physical mobile devices: local headless browser checks cannot establish real-world LCP, INP or CLS.
